# Banners horizontales de los cómics

Agrega aquí un banner por cómic. La página lo buscará automáticamente usando el nombre del archivo indicado abajo. Usa formato **JPG** y estas dimensiones recomendadas:

- **2400 × 1200 px** (proporción 2:1)
- Mantén el personaje o elemento principal cerca del centro o hacia la derecha: el título y la sinopsis se muestran encima, principalmente a la izquierda.
- Deja algo de espacio alrededor del elemento principal para que también se vea bien en pantallas estrechas.

La página ajusta el banner a cada pantalla recortando lo necesario. Si todavía no existe el archivo, se mostrará la portada actual del cómic.

Usa el slug del cómic como nombre, por ejemplo `a-la-deriva-con-mi-perro.jpg`:
