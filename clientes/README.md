# Logos de clientes

Pon aquí el logo de cada cliente (PNG, JPG, SVG o WEBP, fondo transparente si se puede).

Luego agrega el archivo a `logos.json`:

```json
[
  { "file": "nombre-del-archivo.png", "name": "Nombre del cliente" }
]
```

La fila se mueve sola en Proyectos y en el inicio, encima de Nuestros creadores.
